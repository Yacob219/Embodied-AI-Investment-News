# 具身投资观察 · 产品说明

版本 1.0 / 2026-09-27

## 使用目标

为个人投资与产业研究提供中文工作台：找到某周的融资消息，查看公司业务、投资方和原始证据，按统一口径比较可比金额，再回到来源判断。

## 本次交付

周报、跨周筛选、归档、融资面板、来源详情、CSV 与浏览器 PDF、可配置规则。主色深蓝，青绿用于确认状态，保持紧凑的信息密度与移动端阅读体验。无需账户或后端即可浏览已发布的静态研究记录。

## 内容范围

P1：机器人本体、全栈具身智能、机器人基础模型、VLA 与控制。
P2：核心零部件、感知与执行、数据、仿真和相关物理智能基础设施。
P3：与具身智能关联较弱的其他硬科技，只作为外围观察。

排除无关个人动态、没有出处的模型事实。相关候选即使低分也保留；来源文章与真实交易分开建模。同一交易的多篇报道不能重复统计。

## 核验与评分

A 级为官方一手、论文和监管原文；B 级为有采编纠错机制的媒体；C 级为个人及行业自媒体；D 级为来源链不明材料。

字段已校验且有 A 级原始证据，或两个不同证据链的 B 级，可满足自动证据门槛。转载同一消息不增加独立来源数。实体不明、金额冲突与其他风险优先审核。

分数均为 0–100。权重：相关性 25%、影响 25%、可信度 20%、新颖性 10%、重点关注 10%、独立验证 10%。自动简报要求证据门槛通过、相关性至少 70、影响至少 60、无风险。低影响已确认项归入更多关注。未经评分的数据不伪造分数。

待补充：各维度的具体评分锚点和正反例、重大融资定义、分类边界评测。当前规则函数接受上游评分，不宣称已经能自动产生可信评分。

## 金额语义

保留原币、金额文本、金额类型、公告日期与来源。已确认并不等同于交割完成。下界、区间、累计金额及资本承诺需显式说明。原币种榜仅比较同币种精确股权金额；并购不纳入。人民币参考榜沿用原资料的国内榜单和各期汇率日期，保留限定词，单独标注参考口径。

## 数据与来源

本次沿用参考项目六期周报的 407 条记录，保留原摘要、金额、分类、新闻链接与周报期次，原始 JSON 留档。全部记录标为资料待复核，不伪造独立核验结论。数据出处与转换见 DATA_PROVENANCE.md。页面最新资料期次不称为当前周，不承诺市场覆盖完整性。

## 验收范围

每个导航可到达；所有筛选与排名一致；空结果可恢复；来源链接可访问；历史周次正确；未知和模糊金额不进入精确统计；移动端可阅读。统计覆盖仅本地记录集合。当前不声称达到重大事件召回率或自动发布可靠性指标。
